# 问题反馈

如果你在使用 PaperBell 时遇到问题，或发现教程存在错误、遗漏和不清楚的地方，可以通过 **PaperBell 飞书问卷**提交反馈。问卷用于统一收集和整理问题，不是即时聊天或实时客服渠道。

> [!important] 飞书问卷入口
> https://shuang-team.feishu.cn/share/base/form/shrcnNR9UsCGP9YZHLo5l46Hg8b

## 可以反馈什么？

- 插件或工作流无法按照教程正常运行；
- 教程中的路径、字段、截图或操作步骤已经失效；
- 不同系统、主题或插件版本产生兼容问题；
- 某个功能难以理解或缺少必要说明；
- 对 PaperBell 工作流和后续功能的建议。

## 问卷需要填写什么？

当前“用户问题反馈表”包含以下内容：

| 问卷字段 | 是否必填 | 填写建议 |
| --- | --- | --- |
| 问题板块 | 必填 | 选择“软件下载与安装”“工作流联动”“Paperbell相关插件”或“其他插件配置” |
| 用户问题描述与报错 | 必填 | 说明实际现象，粘贴完整报错，并写明原本希望得到的结果 |
| 用户操作步骤 | 必填 | 按顺序说明打开了什么页面、点击了什么功能以及进行了哪些操作 |
| 用户截图与附件 | 选填 | 可上传报错截图、脱敏日志或最小测试文件；没有可以跳过 |
| 用户邮箱 | 必填 | 填写能够正常接收处理结果和补充提问的邮箱 |

问卷没有单独设置“使用环境”字段时，请把操作系统、Obsidian 版本、PaperBell 版本及相关插件版本写在“用户问题描述与报错”中。

如果问题同时涉及多个板块，选择最主要的一个，并在问题描述中补充其他相关插件或工作流。

提交前可以先重启 Obsidian，并使用测试笔记重新操作一次。如果问题只能偶尔出现，请说明大致发生频率，不要写成“每次都能复现”。

## 注意隐私

请勿在问卷或附件中提交：

- API Key、Token、激活码、密码或 Cookie；
- 未发表论文、完整 PDF、审稿信息或真实研究数据；
- 包含个人姓名、电话、邮箱和本机用户名的完整日志；
- 整个 Vault、整个 `.obsidian` 文件夹或未经筛选的插件配置。

截图和日志应只保留与问题直接相关的部分，并把绝对路径中的用户名替换为 `<USER>`。需要提供笔记时，优先使用虚构内容制作最小复现文件。

## 提交之后

反馈会通过飞书问卷集中整理。相同问题不需要反复提交；请确保“用户邮箱”填写正确，维护者可能通过该邮箱反馈处理结果或询问补充信息。问题得到确认后，通用解决办法会逐步补充到 FAQ 或对应教程中。
