# Map View

**【开源链接】**
<https://github.com/esm7/obsidian-map-view>

**【简介】**
这个插件能把带有"地理位置"信息的笔记，全部标注到一张**可交互的地图**上。你给某篇笔记记上一个地点（一所大学、一个城市、一次出差地），它就在地图上变成一个图钉；点这个图钉，就能跳回对应的笔记。还能按标签给图钉换不同颜色和图标（本库里就设了：`#institute` 机构显示成粉色学校图标、`#trip` 出行显示成绿色徒步图标），一眼就能分清类别。

**【使用方法】**
1. 给需要上图的笔记添加地理位置------可以在属性里填经纬度，也可以用插件命令直接从地名搜索并写入。
2. 按 `Ctrl+P` 搜 "Map View" 打开地图，所有带位置的笔记就以图钉形式显示出来。
3. 点图钉可跳到对应笔记；地图可缩放、拖动，还能用查询语句（比如 `tag:#institute`）只筛选某一类地点显示。
4. 想给某类笔记统一换图标颜色，在插件设置的"显示规则"里按标签配置即可。

**【和 PaperBell 的联动】**
PaperBell 库里的机构、学者笔记，往往都带着地域属性（比如某高校在哪座城市）。Map View 正好把这些结构化笔记换了个"地理视角"来看：把散落的机构一次性铺到地图上，就能直观看出你关注的学术资源在地理上的分布------哪个地区集中、哪里还是空白，一目了然，比翻文件夹清单更有空间感。
