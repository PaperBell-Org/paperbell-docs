# 开始之前

## 本页目标

开始安装前，先确认三件事：PaperBell 不是单个插件、第一次练习不使用正式研究资料、所有测试结果都应该能够定位和删除。

预计用时：**5–10 分钟**。

## PaperBell 是一套工作环境

| 组成             | 主要内容                                                      | 在快速上手中的作用                |
| -------------- | --------------------------------------------------------- | ------------------------ |
| Obsidian vault | 编号目录、模板、Base、CSS 与配置                                      | 提供统一的数据结构和工作空间           |
| Obsidian 插件    | PaperBell、Project Manager、ZotLit、Thino、PaperOut 等         | 创建、处理、查询和输出文件            |
| 外部软件与扩展        | Zotero、Zotero Connector、Obsidian Web Clipper、Pandoc 及配套工具 | 保存文献与网页资料，并把写作结果导出为可交付文件 |
| 普通文件           | Markdown、JSON、BibTeX、图片和附件                                | 保存最终可检查、可备份的数据           |

因此，只安装 PaperBell 主插件并不能得到完整工作流；反过来，即使某个插件暂时停用，已经写入的普通 Markdown 文件仍应可以读取。

## 第一次使用独立练习副本

> [!warning] 不要直接在唯一一份正式库中试运行
> 第一次练习可能创建项目、移动输入笔记、写入日记、生成档案和输出文件。请复制一份完整 PaperBell 库作为练习库，并保留原始压缩包或未修改副本。

建议：

1. 将发布包解压到一个新的、容易识别的目录；
2. 不要把练习库直接放进正在同步的正式研究目录；
3. 记录练习开始前的文件数量或保留完整备份；
4. 使用统一的测试名称，便于最后搜索和清理。
