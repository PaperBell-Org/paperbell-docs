# 安装基础软件

## 本页目标

这一页只准备 PaperBell 库外的运行环境。库内已经包含的 Obsidian 插件将在下一页启用；Web Clipper 模板会在打开正确的 vault 后导入，PaperOut 自带资产则在那时检查并按需补齐。

完成快速上手需要两条外部链路：

```text
网页与文献采集：浏览器 → Zotero Connector / Web Clipper → Zotero / PaperBell
首次成稿导出：PaperOut → Pandoc → XeLaTeX / pandoc-crossref → PDF 或 Word
```

| 工具 | 本次是否需要 | 用途 |
| --- | --- | --- |
| Obsidian 桌面版（1.13.4 或更高） | 必需 | 打开 PaperBell vault 并运行库内插件 |
| Zotero + Zotero Connector | 必需 | 保存文献父条目、PDF 和网页元数据 |
| Obsidian Web Clipper | 必需 | 把学者主页或普通网页送入 `20 - Inputs` |
| Better BibTeX | 必需 | 为测试文献生成稳定 citation key，并准备引用数据 |
| ZotLit Companion | 完整 ZotLit 联动需要 | 从 Zotero 端调用 Obsidian，并提供协议与通知能力 |
| Pandoc | 必需 | 执行 PaperOut 的首次格式导出 |
| XeLaTeX | 默认 PDF 工作流需要 | 把 Pandoc 中间结果排版为 PDF |
| pandoc-crossref | 当前 PaperBell 手稿配方需要 | 处理图、表、公式编号和交叉引用 |

## 一、安装 Obsidian 桌面版

从 [Obsidian 官方下载页](https://obsidian.md/download)选择当前操作系统对应的桌面版本。第一次配置不建议从移动端开始，因为 Zotero 连接、社区插件和本地导出工具链主要依赖桌面环境。

安装完成后只需确认：

- Obsidian 可以正常启动；
- 可以打开“管理仓库”窗口；
- 当前账户对准备存放 PaperBell 的目录具有读写权限。

> [!important] 社区插件安全
> Obsidian 社区插件可以读写 vault 中的文件。只使用来自 PaperBell 官方或你能确认来源的完整发布包，并在启用前保留练习库备份。

## 二、安装 Zotero 和 Zotero Connector

1. 从 [Zotero 官方下载页](https://www.zotero.org/download/)安装 Zotero 桌面端；
2. 为当前浏览器安装 Zotero Connector；
3. 打开 Zotero，并在浏览器中访问一篇论文详情页；
4. 点击 Connector，确认可以生成正式父条目；
5. 有访问权限时，确认 PDF 成为父条目下的附件。

Zotero Connector 负责把论文保存到 Zotero，不负责把内容写入 Obsidian。详细边界见 [Zotero Connector](../04-插件介绍/01-Obsidian外插件/01-Zotero-Connector.md)。

## 三、安装 Obsidian Web Clipper

从 [Obsidian Web Clipper 官方页面](https://obsidian.md/help/web-clipper)安装当前浏览器对应的扩展，并把它固定到浏览器工具栏。

浏览器里现在应该有两个容易混淆的入口：

| 浏览器扩展 | 点击后送往哪里 | PaperBell 中的用途 |
| --- | --- | --- |
| Zotero Connector | Zotero 文献库 | 保存论文条目、PDF 和引用元数据 |
| Obsidian Web Clipper | 指定的 Obsidian vault | 保存学者主页、网页选区和其他网络材料 |

这一页只安装扩展。PaperBell vault 尚未打开，因此先不要随意选择同名库；下一页会连接正确的 vault，并导入 `Scholar clipper` 模板。详细介绍见 [Obsidian Web Clipper](../04-插件介绍/01-Obsidian外插件/05-Web-Clipper.md)。

## 四、安装 Zotero 配套插件

### Better BibTeX

[Better BibTeX](../04-插件介绍/01-Obsidian外插件/02-Better-BibTeX.md)用于维护稳定的 citation key，并为后续写作导出 `.bib`。

安装后确认 Zotero 插件列表中可以看到 Better BibTeX，并且测试文献能够生成稳定引用键。

### ZotLit Companion

[ZotLit Companion](../04-插件介绍/01-Obsidian外插件/03-ZotLit-Companion.md)提供 Zotero 端菜单、协议链接和可选的实时通知。它必须与当前 Zotero 和 ZotLit 版本匹配，因此按照对应插件页面和官方说明选择安装包，不要混用其他主版本的 `.xpi`。

如果 Companion 暂时无法连接，后续仍可从 Obsidian 端的 ZotLit 快速切换器选择测试条目；但这只能作为排错期间的替代入口，不代表完整 ZotLit 联动已经验收。

### Ethereal Style（可选）

[Ethereal Style](../04-插件介绍/01-Obsidian外插件/04-Ethereal-Style.md)用于统一 Zotero 批注颜色语义。它不影响 ZotLit 是否能够导入批注，第一次练习可以跳过。

## 五、安装首次导出工具链

快速上手要求实际生成一份导出文件，因此 **Pandoc 不能延后安装**。本教程使用 PaperBell 当前默认的手稿 PDF 工作流完成验收，所以还需要 XeLaTeX 和 pandoc-crossref。

### 1. 安装 Pandoc

按照 [Pandoc 官方安装说明](https://pandoc.org/installing.html)选择当前系统的安装程序或包管理器。不要同时使用多个安装方式，以免 PaperOut 调用到另一份旧版本。

### 2. 安装 XeLaTeX

XeLaTeX 通常由 TeX 发行版提供：

- Windows：MiKTeX 或 TeX Live；
- macOS：MacTeX、BasicTeX 或 TinyTeX；
- Linux：发行版提供的 TeX Live。

完整 TeX 发行版占用空间较大，应在开始下载前预留时间和磁盘空间。第一次编译时如果发行版提示补装宏包，先记录包名，再从发行版自己的包管理器安装。

### 3. 安装 pandoc-crossref

从 [pandoc-crossref Releases](https://github.com/lierdakil/pandoc-crossref/releases)下载与当前 Pandoc 兼容的版本，并确保可执行文件位于系统 `PATH` 或 PaperOut 已配置的额外工具目录中。

### 4. 在终端验收

安装结束后关闭并重新打开终端，依次执行：

```bash
pandoc --version
xelatex --version
pandoc-crossref --version
```

三条命令都应返回版本信息，而不是“找不到命令”。如果终端已经识别、Obsidian 仍然识别不到，完全退出并重新启动 Obsidian。

> [!note] 系统工具不等于 PaperOut 资产
> 上面安装的是本机可执行程序。PaperOut 使用的配方、Lua 过滤器、LaTeX 模板和 CSL 样式属于 vault 内资产；v5.0.1 已随包提供一套基础资产，下一页先检查它们，仅在缺失或需要额外配方、样式时使用资产市场。

## 六、仍然可以延后的能力

| 工具或能力 | 第一次练习如何处理 |
| --- | --- |
| PaperBell AI | 暂不配置，概念卡可以手工建立 |
| Web Clipper Interpreter 模型 | 没有可信模型时可先使用手动学者路径，但之后仍需单独验收自动采集 |
| PaperSearch 本地后端 | 核心已随 v5.0.1 发布包提供，但本地后端默认关闭，不属于首次闭环前置条件；未主动启用时不应要求它连接 |
| 额外 PaperOut 配方与投稿样式 | 先检查发布包内的首次手稿导出资产，缺失时补齐；其他样式进入详细教程后再选 |
