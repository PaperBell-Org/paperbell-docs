## 二、命令面板：统一操作入口

按 `Ctrl+P`（macOS 通常为 `Command+P`）打开命令面板。输入插件名或动作关键词，就能执行项目创建、打开日记、添加学者和新建论文项目等操作。

命令完全搜不到时，优先检查插件是否启用，而不是重复输入不同关键词。{>>建议在这里补一句快捷键说明：示例库里唯一设了自定义快捷键的是 QuickAdd（`Alt+Q` 直接唤起选择列表），而下一页有四步都要用 QuickAdd。但要注意——`.obsidian/hotkeys.json` 被示例库的 `.gitignore` 排除了，所以读者拿到的发布包里**没有**这个快捷键，只能走命令面板。这个差异要么在文档里说明，要么把 hotkeys.json 纳入分发，否则读者按 Alt+Q 没反应会以为装坏了<<}

## 三、属性区与正文区

打开一篇 Markdown 笔记时：

- 顶部属性区保存 `citekey`、`keywords`、`acronym`、`stage` 等结构化字段；
- 正文区保存阅读笔记、日记内容、任务和写作文本；
- 源码模式中，两行 `---` 之间的 YAML 就是属性数据。

快速上手只检查字段是否存在，不随意重命名字段。字段名称发生变化可能导致 Base、模板或插件无法识别。

## 四、Ribbon 与左右侧边栏

最左侧 Ribbon 和左右侧边栏通常提供 Calendar、Thino、Task Genius、PaperOut 等面板入口。面板可以折叠、移动或关闭；找不到图标时仍可以通过命令面板打开对应功能。

记住：面板只是操作和查看入口，真正的数据仍应落在普通文件中。

## 五、浏览器工具栏：两个扩展不要混淆

PaperBell 的采集入口不全在 Obsidian 中：

- 看到论文详情页时点击 **Zotero Connector**，结果先进入 Zotero；
- 看到学者主页或想保留的普通网页时点击 **Obsidian Web Clipper**，结果直接写入当前 PaperBell vault；
- Web Clipper 保存后，文件可能很快被 Inputs Bell 从 `20 - Inputs` 移走，应通过标题、来源 URL 或标签搜索，而不是重复剪藏。

第一次操作前先查看扩展中显示的目标库。浏览器能够打开扩展，不代表它已经连接到当前练习库。

## 六、设置、通知与状态栏

- “设置 → 核心插件”用于启用 Daily Notes 等 Obsidian 自带能力；
- “设置 → 第三方插件”用于启用社区插件；
- 每个插件自己的设置页用于检查目录、模板和连接参数；
- 右上角通知和底部状态栏会显示索引、导入、编译等操作是否完成或失败。

不要在没有记录原值时连续修改多个插件设置。出现问题时一次只调整一个组件。

## 七、五分钟练习

1. 在文件列表中依次展开 `20 - Inputs`、`30 - Metadata`、`40 - Projects` 和 `50 - Outputs`；
2. 打开命令面板，搜索 `新建科研项目`，确认命令存在但先不执行；
3. 搜索 `Daily notes`、`Thino` 和 `ZotLit`，确认各自入口存在；
4. 打开任意测试笔记，区分属性区和正文区；
5. 打开浏览器，分别找到 Zotero Connector 与 Obsidian Web Clipper，并说出二者结果会保存到哪里；
6. 打开设置，找到 PaperBell、ZotLit、Project Manager、Thino 和 PaperOut 的设置页；
7. 返回文件列表，准备开始正式练习。
