# 是否适用于你？

> [!info]
> 👋 Hey, 欢迎关注本项目，无论你来自哪里

## 🧑‍🎓 你应该认同以下理念

- [x] 想用 Obsidian
- [x] 长期以学术为志业
- [x] 输入是为了更好的输出
- [x] 论文只是学术共同体交流工具
- [x] 想法需要积累，更需要互相产生链接
- [x] 形式可以重复，内容比形式更重要，想法比内容更重要

## 🤔 众多 Obsidian 库，为什么选择 PaperBell？

- 🤝🏻 社区支持：我们有着使用 Obsidian 从事科研工作的用户社区，有问必答
- 🙋‍♀️ 专业插件：CIMPO 各层的 PaperBell 自动化组件由团队维护，并与 ZotLit、Templater、QuickAdd、Dataview 等社区插件协作
- ⌛️ 长期主义：项目持续维护，并以发布包中的实际版本与配置为准
- 🎓 理论基础：示例库基于成熟的方法论框架设计
