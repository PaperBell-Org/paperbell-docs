# 这份手册怎么读

PaperBell 手册由产品介绍、快速上手、详细教程、插件介绍、高级定制和 FAQ 六部分组成。它既可以从头学习，也可以按当前任务查阅，不需要每个人都采用同一条路线。

> [!important] 先分清“教程”和“参考手册”
> [快速上手](../02-快速上手/index.md)与[详细教程](../03-详细教程/index.md)适合连续阅读和动手练习；[插件介绍](../04-插件介绍/index.md)、[高级定制](../05-高级定制/index.md)与[FAQ](../06-FAQ与问题反馈/index.md)更适合遇到具体需求时查阅。

## 路线一：第一次使用 PaperBell

适合第一次接触 Obsidian，或者虽然用过 Obsidian，但还没有使用过 PaperBell 完整工作流的读者。

### 推荐路线

```text
是否适用于你与使用场景
→ 快速上手全部页面
→ 按详细教程首页列出的顺序阅读工作流页面
→ 插件介绍与 FAQ 按需查阅
```

### 怎样阅读

1. 先阅读[是否适用于你](02-是否适用于你.md)和[PaperBell 的使用场景](03-PaperBell%20的使用场景.md)，确认 PaperBell 的目标与自己的需求一致；
2. 完整执行[快速上手](../02-快速上手/index.md)，使用可删除的测试资料完成软件安装、Web Clipper 网页采集、文献导入、项目与日记、学者与机构、概念卡和 Pandoc 首次导出；
3. 再按照[详细教程](../03-详细教程/index.md)的顺序，从 CIMPO 框架开始理解每条工作流为什么这样设计；
4. 遇到具体组件问题时，再进入插件介绍或 FAQ，不必提前通读所有插件页面。

> [!tip] 新手的完成标准
> 不是“把所有页面看完”，而是能够找到每一步产生的真实文件，并成功打开 PaperOut 生成的第一份 Word 或 PDF。

## 路线二：已有 Obsidian 或 Zotero 使用经验

适合已经有 Obsidian vault、Zotero 文献库或其他知识管理流程，希望判断怎样采用 PaperBell、并逐步迁移正式资料的读者。

### 推荐路线

```text
核心设计理念与使用场景
→ 用快速上手验收独立练习库
→ 详细教程理解数据流
→ 按实际工作流查阅插件介绍
→ 验收稳定后再处理正式资料
```

### 怎样阅读

1. 重点阅读[核心设计理念](01-核心设计理念.md)、[PaperBell 的使用场景](03-PaperBell%20的使用场景.md)和[详细教程首页](../03-详细教程/index.md)，理解 PaperBell 的对象结构与工作流顺序；
2. 可以略读基础界面说明，但仍应把[快速上手](../02-快速上手/index.md)作为环境验收清单，在独立练习副本中跑通一次完整闭环；
3. 按照“项目 → 文献 → 日记 → 学者与机构 → 概念卡 → PaperOut”的顺序检查现有资料应进入哪里，以及哪些字段、标签和链接承担关联作用；
4. 只阅读当前链路涉及的插件页面，不要因为已经熟悉 Obsidian 就一次性重做 PaperBell 的全部默认设置；
5. 测试库稳定后，再分批处理正式文献、项目和笔记，每次迁移后检查文件位置与反向链接。

> [!warning] 熟悉工具不等于熟悉这套数据约定
> 即使已经使用多年 Obsidian 或 Zotero，也不要跳过 vault 根目录、Inputs Bell 移动规则、Web Clipper 目标库和 PaperOut 导出资产的检查。

## 路线三：高级定制与开发型用户

适合熟悉 YAML、模板、Bases、JavaScript、Obsidian 插件或 Pandoc，希望修改 PaperBell 数据结构和自动化行为的读者。

### 推荐路线

```text
核心设计理念
→ CIMPO 与完整工作流数据流
→ 插件体系及核心插件边界
→ 高级定制
→ 用快速上手闭环做回归验收
```

### 怎样阅读

1. 先阅读[核心设计理念](01-核心设计理念.md)和[CIMPO 学术生涯管理框架](../03-详细教程/01-CIMPO-学术生涯管理框架.md)，确认每类对象的目录、字段和职责；
2. 通过[插件体系总览](../04-插件介绍/index.md)理解浏览器、Zotero、Obsidian 插件和外部程序之间的边界，再查阅准备修改的核心插件页面；
3. 根据目标进入[ZotLit 模板自定义](../05-高级定制/01-ZotLit模板自定义.md)、[笔记关联逻辑](../05-高级定制/02-笔记关联逻辑.md)或[笔记导出模板](../05-高级定制/03-笔记导出模板.md)；
4. 修改前保留可恢复副本，并记录目录、字段、模板与插件设置的原值；
5. 修改后重新执行[快速上手闭环](../02-快速上手/05-跑通第一个科研闭环.md)，检查采集、归位、关联、查询和导出是否仍然成立。

高级用户可以略过基础操作演示，但不应跳过默认系统的基线验收。否则出现问题时，很难判断是发布包、运行环境还是自己的定制造成的。
